Install in Chub

  1. Download your CSS file above.
  2. Open Chub profile → Edit Theme, or in a chat use bottom-left kebab → Change Theme.
  3. Choose Upload Custom CSS and select the downloaded file. Leave other theme settings on Default.

To remove it, use Clear Custom CSS. Chub accepts a file upload; there is no paste box.
