Chub UI Reference Capture

One-run page inspection

This helper captures the current page's visible element structure, selector paths, computed layout and styles, stylesheet references, and root CSS variables. It does not capture page text, typed values, links, cookies, storage or network payloads.

It runs locally in your browser. It does not send captured information to KM Themes.

How to use it

  1. Open Chub in Firefox with MobiDevTools.
  2. Open the Chub tab, then open MobiDevTools → Console.
  3. Return here, tap Copy capture script, then switch back to the Console.
  4. Paste the script into the Console input and tap Run.
  5. Allow the browser to download the JSON file. Attach that file in your chat with ChatGPT.

Capture one UI state at a time. For a different view, navigate to that Chub screen and run the same script again.

Privacy scope

Only structural selectors and computed visual properties are collected. No message text, character descriptions, form contents, account identifiers, cookies, authentication tokens or request bodies are read.

Do not run third-party inspection tools on private conversations unless you are comfortable inspecting that page. This helper intentionally avoids collecting conversation content.
